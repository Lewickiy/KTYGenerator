# Procedural KTY Generator

**Версия документа:** 1.2

---

# 1. Общая информация

## 1.1 Название проекта

**Procedural KTY Generator**

---

## 1.2 Назначение проекта

Проект предназначен для процедурной генерации цифровых моделей картонных тарных ящиков (КТЯ) через Blender Python API.

Генератор создаёт экспортируемые параметрические модели транспортной тары для использования в:

* симуляции автоматизированных складов;
* цифровых двойниках логистических систем;
* моделировании работы AGV;
* визуализации складских процессов;
* генерации тестовых окружений.

Генерация выполняется полностью процедурно.

Не допускается использование:

* внешних 3D-моделей;
* импортированных mesh-файлов;
* внешних текстур;
* готовых CAD-моделей.

---

# 2. Область ответственности

## 2.1 Генератор КТЯ отвечает за:

* создание геометрии коробки;
* создание материалов;
* изменение уровня детализации;
* моделирование состояния коробки;
* расчёт массы пустой тары;
* подготовку экспортных файлов;
* создание визуального представления объекта;
* генерацию метаданных.

---

## 2.2 Генератор КТЯ не отвечает за:

* генерацию товаров;
* размещение товаров внутри коробки;
* количество товаров;
* массу содержимого;
* характеристики товаров.

Товары создаются отдельным программным модулем:

```
Product Generator
```

Связь между товаром и КТЯ осуществляется внешней системой управления складом.

---

# 6. Массовая модель

## 6.1 Масса пустого КТЯ

Генератор должен хранить массу самой тары:

Параметр:

```
emptyWeight
```

Пример:

```
0.7 кг
```

---

## 6.2 Общая масса

Масса содержимого отсутствует в данном генераторе.

Расчёт полной массы выполняется внешней системой:

```
TotalWeight =
KTY emptyWeight +
External Content Weight
```

---

# 7. Уровни детализации (LOD)

Генератор должен поддерживать несколько уровней качества.

---

# 7.1 Ultra Low

Назначение:

* массовая симуляция склада;
* большое количество объектов;
* расчёт логистики.

Особенности:

* один простой mesh;
* отсутствие клапанов;
* отсутствие толщины картона;
* отсутствие внутренних элементов.

Полигональность:

```
6-12 polygons
```

---

# 7.2 Low

Назначение:

* общий вид склада.

Особенности:

* форма коробки;
* базовый материал картона;
* упрощённая геометрия.

Полигональность:

```
50-100 polygons
```

---

# 7.3 Medium

Назначение:

* визуализация рабочих зон.

Добавляются:

* толщина картона;
* клапаны;
* линии сгиба;
* технологические швы.

---

# 7.4 High

Назначение:

* демонстрационные сцены.

Добавляются:

* реалистичные края;
* внутренняя поверхность;
* дополнительные элементы картона.

---

# 7.5 Ultra High

Назначение:

* презентационный рендеринг.

Добавляются:

* микродефекты;
* неровности;
* деформация поверхности;
* детализированные повреждения.

---

# 8. Состояния КТЯ

Генератор должен поддерживать состояния объекта.

---

# 8.1 CLOSED

Закрытая коробка.

Характеристики:

* верхние клапаны закрыты;
* стандартное транспортное состояние.

---

# 8.2 OPEN

Открытая коробка.

Параметры:

```
lidAngle
```

Диапазон:

```
0-180 градусов
```

Примеры:

```
0°   закрыто
90°  открыто
180° полностью раскрыто
```

---

# 8.3 DAMAGED

Повреждённая коробка.

Параметр:

```
damageLevel
```

Диапазон:

```
0.0 - 1.0
```

Возможные повреждения:

* смятие углов;
* деформация стенок;
* разрывы картона;
* нарушение формы;
* следы эксплуатации.

---
